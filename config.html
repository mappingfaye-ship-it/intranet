Google (optionnel) : connexion en un clic
Firebase > Authentication > Méthode de connexion > Google : active-le. Copie l'« ID client Web ». Dans Google Cloud > Identifiants > ton ID client > « Origines JavaScript autorisées », ajoute l'adresse de ton site (https://TON-NOM.github.io).


E-mails (optionnel) : EmailJS
Crée un compte gratuit sur emailjs.com, connecte un service e-mail, et un template qui utilise {{to_email}} (destinataire), {{subject}} et {{message}}.
